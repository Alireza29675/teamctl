# TeamCTL core

Shared Rust library for TeamCTL, the open-source platform for autonomous teams of agents.

`team-core` provides the compose schema, configuration validation, runtime descriptors, artifact rendering, `tmux` supervision and SQLite mailbox schema used by the TeamCTL binaries. It also provides team-registry, session and YAML editing utilities.

This is a library crate. To define and run a team, start with the [TeamCTL setup guide](https://teamctl.run/getting-started/).
